# Сайт-портфолио (прототип)

Опубликован: https://p4rzifalus.github.io/cozy-portfolio/ — обновляется сам после каждого push в `main`
(GitHub Actions: `.github/workflows/deploy.yml`). В репозитории только сайт; Blender-сцены и скрипты живут в родительской папке проекта.

Комната из Blender в браузере: Vite + React + React Three Fiber (three.js).

## Запуск
```
npm install
npm run dev        # http://localhost:5173
```

## Откуда берётся комната
Всё в `public/room/` делает Blender-скрипт `../blender/scripts/export_site.py` (после `bake_all.py bake` и `masks`):
- `room.glb` — геометрия, камеры 1 и 2, самосветящиеся части (неон, экран, город, лампочка) со своими материалами;
- `<Имя>_albedo.webp` — цвет предмета (A — прозрачность листьев), `<Имя>_light.webp` — запечённый свет
  (лог-кодирование, A — шум мазков), `<Имя>_mask_<источник>.webp` — свет мерцающего источника;
- `site.json` — какие файлы у какого предмета, фоновый свет, константы шейдера, мерцание.

## Код
- `src/painterly.ts` — шейдер «живописного» стиля (повторяет группу Painterly из Blender) + цветокоррекция;
- `src/flicker.ts` — мерцание лампы, экрана, неона, фонаря (те же числа, что `blender/scripts/flicker.py`);
- `src/Room.tsx` — загрузка комнаты, материалы, камера: курсор у правого края → поворот головы к шкафу, лёгкий параллакс.
